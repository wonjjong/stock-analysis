# Signalist 문서

이 문서는 현재 저장소의 코드, Django 마이그레이션, 테스트를 기준으로 정리한 운영·설계 문서다. 제품의 목표나 과거 실험을 현재 제공 기능으로 오해하지 않도록 각 문서는 **구현됨**, **참조 전용**, **향후 결정 필요**를 구분한다.

## 현재 범위

현재 운영 가능한 제품은 뉴스 수집·분석과 요청 기반 종목 리서치다. 뉴스는 목록 정보와 파생 분석을 저장하고, 리서치는 공개 시장·공시·뉴스 근거를 조회해 단일 종목 AI 분석과 종목 비교 랭킹을 제공한다. 리서치 결과는 저장하지 않으며 백테스트와 포트폴리오 기능은 제공하지 않는다.

## 문서 갱신 규칙

- 도메인 규칙, 상태값, 저장 구조, 외부 연동 계약을 바꾸면 같은 변경에서 해당 도메인 문서를 갱신한다.
- 정책 문서는 코드가 강제하거나 운영자가 실제로 수행하는 규칙만 현재 정책으로 쓴다. 희망 사항은 `향후 결정 필요`로 적는다.
- 화면·명령의 경로는 `backend/signalist/urls.py`와 `backend/news/management/commands/`를 기준으로 확인한다.
루트 [README](../README.md)는 빠른 실행을, 이 디렉터리는 기능별 계약과 운영 기준을 다룬다.
