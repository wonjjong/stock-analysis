# 정책 문서

정책은 코드·설정·운영 절차가 현재 강제하는 규칙을 기록한다. 법률 자문이나 미구현 통제의 선언이 아니다. `향후 결정 필요` 항목은 현재 보호 장치가 없다는 뜻이며, 배포나 기능 확장의 전제 조건으로 취급한다.

| 정책 | 다루는 문제 |
| --- | --- |
| [아키텍처 정책](architecture.md) | 경계, 의존성, 모델·마이그레이션 소유권 |
| [데이터·보안 정책](data-and-security.md) | 외부 수집, 저작권, URL 안전성, 비밀값, 접근 통제 |
| [운영 정책](operations.md) | 실행 절차, 상태 관측, 장애 복구, 배포 전 점검 |
| [품질 정책](quality.md) | 테스트, parity, 린트, 문서 갱신 |

정책 변경은 해당 정책 문서와 이를 강제하는 코드/테스트를 같은 변경에서 갱신한다. 현재 코드가 정책을 충족하지 못하는 경우에는 문서를 이상적인 상태로 바꾸기보다 공백을 명시하고 별도 작업으로 추적한다.
